Java Experiment Lab

Javaを学びながら、小さなプログラムを実験・観察するための場所。まずは基礎を確かめ、少しずつゲーム制作にもつなげていきます。

この実験室について

ここでは、コードを書き、実行し、結果を見て、なぜそう動くのかを自分で確かめます。完成を急がず、小さな実験を積み重ねます。

01 / Learn
Javaの基礎
変数、条件分岐、繰り返し、メソッド、クラス。
02 / Experiment
動作を確かめる
入力や値を変えて、実行結果の違いを観察。
03 / Create
ゲーム制作へ
学んだ処理を組み合わせ、小さなゲームを作る。
